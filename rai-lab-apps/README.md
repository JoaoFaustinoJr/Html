## Padrão técnico do R.A.I. Lab

Os novos aplicativos devem, sempre que possível:

- funcionar primeiro no celular;
- ser instaláveis como **PWA**;
- manter um endereço oficial permanente;
- receber atualizações sem reinstalação;
- preservar uma versão estável antes de cada nova etapa experimental;
- priorizar funcionamento offline quando adequado;
- guardar progresso localmente por padrão;
- evitar cadastro obrigatório e coleta desnecessária de dados;
- oferecer acessibilidade e Modo Relaxar quando fizer sentido;
- usar a identidade **R.A.I.** de forma discreta e profissional;
- identificar a autoria como **Prof. João Faustino Junior**;
- evitar Fullscreen API e bloqueio de orientação; usar apenas modo de foco interno quando necessário;
- separar núcleo funcional de camadas de interface, experiência e PWA para reduzir regressões.

## Fluxo de desenvolvimento

1. Definir objetivo pedagógico do app.
2. Criar protótipo experimental em rota separada.
3. Testar no celular e em sala.
4. Registrar feedbacks.
5. Corrigir regressões sem alterar a versão oficial.
6. Validar a versão experimental.
7. Promover a versão validada para o canal oficial.
8. Manter histórico de versões e possibilidade de recuperação.
