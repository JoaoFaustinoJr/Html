# Maker Quest — R.A.I. Tutora

Aplicativo independente convertido da experiência original **Maker Quest — Jornada STEAM** em Google Colab.

## Campanha preservada
Code Arena → Variáveis → Robótica → Algoritmos → AgroTech → Dados → Cyber → Boss.

## Identidade
Mantém a linguagem visual do Tangram Educativo e a mesma personagem R.A.I., mas é um aplicativo separado e exclusivo do Maker Quest.

## Recursos
- PWA instalável;
- funcionamento offline após o primeiro acesso;
- progresso e XP salvos no aparelho;
- R.A.I. com voz, dicas e exemplos;
- modo conforto;
- interface responsiva para celular, tablet e computador;
- personalização de título, escola, turma e professor.
